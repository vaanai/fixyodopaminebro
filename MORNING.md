# Morning checklist

1. Install the APK. Allow this source if Android asks.
2. Open Quiet, leave Balanced unless you want another preset.
3. If the accessibility toggle is greyed out: App info → Quiet → ⋮ → Allow restricted settings. Then enable Quiet. Menu names vary.
4. Battery: Unrestricted or Don't optimize. Lock Quiet in Recents. If the phone has Autostart, turn it on for Quiet.
5. Capture a snapshot of each enforced surface (Instagram Home, Reels; TikTok For You, Following) plus inbox and thread. The 3-second countdown is the time to switch apps.
6. Use the phone. Home, Reels, For You, and Following should redirect once or show the sheet. Threads, inbox, profile, and stories should stay usable. In-chat reels are not detected yet.
7. If Quiet blocks a chat, or the sheet will not go away: turn the Quiet accessibility service off, then send the snapshots.
8. Put snapshots you choose to share into `fixtures/real/`. Edit rule JSON only after the decoy tests still pass.
